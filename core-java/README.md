# core-java

Núcleo do sistema, em **Java + Spring Boot**. Entra na **etapa 2**.

Responsável por:

- Integrações via API: GitHub, Gupy, Adzuna, Careerjet, Greenhouse/Lever
- Endpoint de ingestão para o scraper (`POST /api/ingestao/vagas`)
- Filtro júnior, score, deduplicação, PostgreSQL (Flyway) e notificação

Stack: Java 21/25 · Spring Boot · Maven · RestClient · Resilience4j · Spring Data JPA · Flyway · JUnit 5 · AssertJ · WireMock · Testcontainers.
